# Mira Vellani – Official Music Wiki

Responsive, buildfreie GitHub-Pages-Website für Mira Vellani, eine virtuelle KI-Künstlerin.

## Website
Vorgesehene Adresse: https://martinsm72.github.io/mira-vellani-wiki/
Diese Adresse ist erst nach Aktivierung und erfolgreichem GitHub-Pages-Deployment erreichbar.

## GitHub Pages aktivieren
1. Repository → Settings → Pages öffnen.
2. Unter Build and deployment als Source **Deploy from a branch** wählen.
3. Branch **main**, Ordner **/ (root)** wählen und **Save** anklicken.
4. Unter Actions den erfolgreichen **pages build and deployment**-Lauf abwarten.
5. Die oben angegebene Adresse öffnen. Änderungen an main werden danach automatisch veröffentlicht.

Kein npm, Build-System, API-Key oder eigener Server erforderlich. Die Datei .nojekyll deaktiviert die Jekyll-Verarbeitung.

## Dateien und Vorschau
- index.html: vollständige Inhalte, Navigation, native Tracklisten und Suno-Embed.
- styles.css: responsive Gestaltung, Tastaturfokus und reduzierte Bewegung.
- .nojekyll: statische Veröffentlichung ohne Jekyll.

Lokal im Projektverzeichnis: `python -m http.server 8000`, dann http://localhost:8000 aufrufen.

## Inhalte ergänzen
Nur bestätigte Angaben in index.html eintragen. Das EP-Cover ist das vom Nutzer bereitgestellte Original. Die Galerie enthält die fünf vom Nutzer bereitgestellten offiziellen Porträt-, Musikvisual- und Markenmotive sowie das EP-Cover. Die Bilder werden vollständig ohne Beschnitt dargestellt. Der Sonnenuntergang ist eine abstrakte CSS-Gestaltung, keine biografische Ortsangabe. Keine realen Herkunftsorte, Lebensdaten oder Künstlerbiografie ergänzen, sofern nicht ausdrücklich bestätigt.

Verifizierte Social-URLs erst nach Freigabe als echte Links ergänzen. Der vorhandene Suno-Link führt zum bestätigten Song, nicht zu einem angenommenen Künstlerprofil.

## Player und Datenschutz
Der responsive Suno-iframe lädt ohne automatischen Wiedergabestart. Der externe Dienst verarbeitet Verbindungsdaten gemäß seinen eigenen Regeln. Ein sichtbarer Direktlink bleibt als Alternative verfügbar, falls Browser, Netzwerk oder Suno das Einbetten verhindern. Die Website nutzt keine eigenen Analysewerkzeuge, Cookies, externen Schriftarten oder JavaScript-Abhängigkeiten.

## Qualitätsprüfung
Semantische Bereiche, deutsche Dokumentsprache, Sprunglink, Tastaturfokus, native Details-Elemente und Layouts für Mobilgeräte sind enthalten. Der Player benötigt eine Internetverbindung. Vor Veröffentlichung offizieller Bilder Bildrechte und Alternativtexte ergänzen.
